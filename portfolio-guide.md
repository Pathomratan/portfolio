# Portfolio Website Task

ให้นักเรียนสร้างเว็บไซต์ Portfolio ส่วนตัวด้วย React โดยอ้างอิง checklist และรูปแบบเว็บไซต์ตัวอย่างแนว dark futuristic interface

## Required Pages

- Home
- Projects
- About
- Contact
- 404 Page

## Core Requirements

- แสดงชื่อ, role, location และ contact information
- มี GitHub และ LinkedIn link
- มี About Me 3-5 ประโยค
- มี Experience / Education และ Generation Thailand certification
- มี technical skills และ soft skills อย่างน้อย 3-5 รายการ
- มี project อย่างน้อย 2 โปรเจกต์
- แต่ละ project ต้องมี screenshot, description, tech stack, GitHub และ live demo
- เว็บไซต์ต้อง responsive ทั้ง desktop และ mobile
- ไม่มี placeholder content ในงานสุดท้าย

## Design Direction

- ใช้ธีม dark futuristic หรือ technology-inspired
- มี main container ขนาดใหญ่ มุมโค้ง
- ใช้ typography ที่อ่านง่ายและเข้ากับธีม
- ใช้ navigation ชัดเจน เช่น Home, Projects, About, Contact
- ใช้สี accent อย่างสม่ำเสมอ
- มี visual element เช่น profile image, project screenshot หรือ UI status text

## Final Checklist

- [ ] Home page แนะนำตัวชัดเจน
- [ ] Projects page มีอย่างน้อย 2 โปรเจกต์
- [ ] Project card มี screenshot, description, tech stack และ links
- [ ] About page อธิบายตัวตน ประสบการณ์ และเป้าหมาย
- [ ] Contact page มี contact information และ form
- [ ] 404 page มี link กลับ Home
- [ ] Navigation ใช้งานได้ทุกหน้า
- [ ] Responsive บน mobile
- [ ] Links ทุกอันกดได้จริง
- [ ] Deploy แล้วเปิดผ่าน HTTPS ได้
