# React Portfolio Starter

Starter project สำหรับสร้าง portfolio website ตามโจทย์ใน `portfolio-guide.md`

## Run Project

```bash
npm install
npm run dev
```

## Pages

- Home
- Projects
- About
- Contact
- 404 Not Found

## Edit Content

แก้ข้อมูล portfolio ได้ที่:

- `src/data/portfolio.js`

แก้หน้าตาเว็บไซต์ได้ที่:

- `src/styles.css`
